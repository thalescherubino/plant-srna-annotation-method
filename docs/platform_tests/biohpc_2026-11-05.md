This test checks the instructions in [setup.md](../setup.md) on a shared Linux server before applying the method to new species. It covers installation and upstream example runs only; no new-species analysis was run.

## Issues found and changes made

1. **Phasis dependencies float.** Phasis pins only NumPy and scikit-learn, so pip installed pandas 3.0.6 and matplotlib 3.11.2. Added `envs/phasis.pip-constraints.txt` with the tested versions. A fresh environment built with the constraints repeated the pytest result.
2. **miRador upstream environment uses Anaconda `defaults`.** The upstream `environment.yml` mixes `defaults` with old conda-forge labels. The README fallback recipe pins `python=3.7.13`, which conda-forge lacks; relaxing it to 3.7.12 built and ran, giving the baseline.
3. **miRador on recent Python.** `Bio.pairwise2` is deprecated in Biopython 1.88 and PyPDF2 is no longer provided. Three changes made it run on Python 3.12, with outputs identical to the baseline:
   - `PairwiseAligner` with identical scoring, verified on 20,000 random miRNA-like pairs;
   - `pypdf.PdfWriter`, with sorted page order;
   - `samtools faidx` via `subprocess.run(check=True)`.
4. **miRador hardcodes `samtools`.** It ignores `samtoolsPath` for `faidx`; this is documented, not changed.
5. **Running examples in place modifies checkouts.** Documented running the miRador test in an exported copy.

## Not tested

- ShortStack and miRScore were not run on example data; only installation and help were checked.
- The structural RNA branch was not run on a genome, and no Rfam release was downloaded.
- Other operating systems, and macOS in particular, were not tested.
