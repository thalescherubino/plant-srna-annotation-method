# Release checklist

- Record assembly accession, source, checksum, contig naming, coordinate conventions, organelle scope and annotation release.
- Describe libraries, QC, sample provenance, processing, and known gaps; protect unpublished or restricted data.
- Record evidence sources, licenses, tool versions, commands, parameters, inputs, checksums and output status.
- Preserve locus, product and sequence-equivalence relationships; distinguish ambiguous assignments and avoid double-counting.
- Publish canonical and exploratory tiers separately, including decision rules and an exclusion/review ledger.
- Validate FASTA IDs and alphabets, GFF3 coordinates and parents, class boundaries, expected counts and package checksums.
- Record the applicability and limitations of release policies; specify which stages require human review.
- Provide versioned reference files, a manifest, a changelog and a reproducible validation report.
